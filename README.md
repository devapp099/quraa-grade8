# قُرعة — الصف الثامن

نسخة مستقلة من مشروع قُرعة لمدرسة خوله بنت ثعلبه للبنات، للعام الدراسي 2026/2027.

- الثامن / 1: 36 طالبة.
- الثامن / 2: 35 طالبة.
- المجموع: 71 طالبة؛ مصدر الأسماء الملفان ثامن1.xls وثامن2.xls.
- تتضمن البيانات الأسماء وترتيبها في الشعبة فقط؛ قوائم الهيئة التعليمية فارغة ويمكن إضافتها من الواجهة.

يحافظ البرنامج على التصميم والمظاهر والصوت، والاختيار دون تكرار، والتناوب بين القوائم، وسجل الجلسات وتصدير النتائج والنسخ الاحتياطي.

## التشغيل

افتحي `index.html` مباشرة بعد تنزيل المشروع وفك الضغط، أو استخدمي `npm run serve`. البيانات محفوظة في المتصفح، بمفتاح مستقل `quraa-grade8-v1`.

## التحقق

`npm test`، و`node --check app.js`.
